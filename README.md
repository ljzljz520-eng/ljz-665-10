# 演播室器材档案管理系统

演播室综合管理平台子模块，对 **摄像机 / 灯光 / 收音 / 切换台** 四类器材进行档案化管理，
支持器材编号、存放位置、借用状态、责任人、附件等字段，并按角色隔离查看与编辑权限。

## 快速启动

```bash
node server.js
# 打开浏览器访问 http://localhost:3000
```

纯 Node.js 实现，零外部依赖，数据持久化在 `data/db.json`，附件存储在 `data/uploads/`。

## 演示账号与角色权限

| 账号 | 密码 | 角色 | 查看 | 新增 | 编辑 | 删除 | 附件上传/删 | 附件下载 |
|---|---|---|---|---|---|---|---|---|
| admin | admin123 | 系统管理员 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| keeper | keeper123 | 器材管理员 | ✅ | ✅ | ✅ | ❌ | ✅ | ✅ |
| viewer | viewer123 | 普通员工 | ✅ | ❌ | ❌ | ❌ | ❌ | ✅ |

权限在前端（按钮显隐）与后端（接口鉴权，越权返回 403）双重校验。

## 功能演示路径（增删改查）

1. 登录后通过左侧平台菜单进入「演播室器材档案」；
2. **查**：分类页签（摄像机/灯光/收音/切换台）、状态筛选、关键字搜索；点击「详情/附件」查看完整字段；
3. **增**：点击「＋ 新增器材」填写编号、名称、分类、位置、状态、责任人；
4. **改**：行内「编辑」按钮修改任意字段（如借用状态 在库→借出）；
5. **删**：行内「删除」（仅 admin）；
6. **附件**：详情弹窗中上传 / 下载 / 删除附件（CAM-001 预置了说明书附件可下载演示）；
7. **权限演示**：换 viewer 登录，所有操作按钮消失；换 keeper 登录，删除按钮消失且接口返回 403。

## API 一览

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | /api/login | 登录获取令牌 | 公开 |
| GET | /api/me | 当前用户与权限 | 登录 |
| GET | /api/meta | 分类/状态枚举 | 登录 |
| GET | /api/equipment | 列表（支持 category/status/q 过滤） | view |
| POST | /api/equipment | 新增 | create |
| GET/PUT/DELETE | /api/equipment/:id | 详情/编辑/删除 | view/update/delete |
| POST | /api/equipment/:id/attachments?filename= | 上传附件（原始字节流） | attach |
| GET/DELETE | /api/equipment/:id/attachments/:attId | 下载/删除附件 | view / attach |
