# 🎬 演播室器材档案平台（Studio Gear Archive）

面向演播室的器材台账后台：统一管理**摄像机、灯光、收音、切换台**四大类设备档案，
字段涵盖**器材编号、存放位置、借用状态、责任人、附件**等；内置三档角色，
**查看与编辑权限分离**；平台左侧菜单直达各功能页，可完整演示增删改查。

零第三方依赖（Node.js 内置模块 + 原生前端），克隆即可运行。

## 快速开始

```bash
npm start          # 启动服务（首次运行自动生成演示数据）
# 打开 http://localhost:3000
```

| 命令 | 说明 |
| --- | --- |
| `npm start` | 启动平台（默认 3000 端口，`PORT=8080 npm start` 可改端口） |
| `npm run seed` | 重置并重新生成演示数据 |
| `npm run demo` | 运行接口演示脚本（权限边界 + 增删改查断言） |

## 演示账号（角色权限分离）

| 账号 | 密码 | 角色 | 查看 | 新增/编辑 | 删除档案 | 用户管理 |
| --- | --- | --- | :-: | :-: | :-: | :-: |
| `admin` | `admin123` | 系统管理员 | ✅ | ✅ | ✅ | ✅ |
| `editor` | `edit123` | 器材管理员 | ✅ | ✅ | ❌ | ❌ |
| `viewer` | `view123` | 普通查看员 | ✅ | ❌ | ❌ | ❌ |

> 权限在**服务端逐接口校验**（越权返回 403），前端按钮仅做展示控制。

## 平台菜单与功能

```
🎬 演播室器材档案
├─ 工作台
│   └─ 📊 总览面板      器材总数 / 借用中 / 在库 / 附件统计 + 分类分布图 + 权限矩阵
├─ 档案管理
│   └─ 📋 器材档案      检索（关键字/类别/状态）· 新增 · 编辑 · 删除 · 详情 · 附件上传/下载/移除
└─ 系统管理（仅管理员）
    └─ 👥 用户与权限    用户列表 · 新建 · 编辑角色/重置密码 · 停用 · 删除
```

## 器材档案字段

器材编号（唯一）、类别（摄像机/灯光/收音/切换台）、名称、品牌、型号、
**存放位置**、**借用状态**（在库/借用中/维修中/已报废）、**责任人**、责任人电话、
购置日期、备注、**附件**（点击/拖拽上传，支持下载与移除，单文件 ≤ 20MB）。

## 接口一览

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| POST | `/api/auth/login` | 公开 |
| GET | `/api/auth/me` | 登录 |
| GET/POST | `/api/equipment` | 查看 / 编辑 |
| GET/PUT/DELETE | `/api/equipment/:id` | 查看 / 编辑 / 删除 |
| POST/DELETE | `/api/equipment/:id/attachments(/:fileId)` | 编辑 |
| GET | `/api/files/:fileId` | 查看（附件下载） |
| GET | `/api/stats` | 查看 |
| GET/POST/PUT/DELETE | `/api/users(/:id)` | 管理员 |

## 目录结构

```
server/
  index.js   # HTTP 服务：路由、RBAC 校验、附件存取、静态资源
  db.js      # JSON 文件数据库（data/gear.json + data/files/）
  auth.js    # scrypt 口令哈希 + HMAC 签名令牌 + 角色权限表
  seed.js    # 演示数据（3 账号 + 10 条器材 + 示例附件）
public/
  index.html / app.js / styles.css   # 单页应用（登录、菜单、CRUD、权限控制）
scripts/
  demo.sh    # 权限边界与增删改查的接口演示
data/        # 运行时生成（已 gitignore）
```

## 演示建议（3 分钟）

1. `admin` 登录 → 总览面板看统计与权限矩阵 → 器材档案新增一条并上传附件 → 用户管理新建账号。
2. 退出后 `editor` 登录 → 可编辑/上传附件，但**删除按钮不可见**，访问用户管理返回 403。
3. 退出后 `viewer` 登录 → 仅可检索、查看详情、下载附件，所有写操作均被拒绝。
